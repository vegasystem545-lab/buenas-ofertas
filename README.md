# Buenas Ofertas

Sitio web de venta de productos de limpieza sueltos y mercadería de ocasión, con pedidos y cálculo de envío por zona.

## Características

- Formulario de pedidos con nombre y dirección
- Selector de productos con precios
- Cálculo de envío por zona
- Total automático
